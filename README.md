# NLP Project

## Overview

This repository contains two independent but complementary NLP modules:

1. **Resume Information Extractor** – A lightweight Python script that uses regular expressions to pull email addresses and phone numbers from resume texts. It processes multiple sample resumes and stores the extracted data in a structured `output.json` file.
2. **Sentiment Classification System** – A beginner‑friendly Jupyter notebook that demonstrates a full sentiment‑analysis pipeline:
   * Load a CSV dataset.
   * Preprocess text (lower‑casing, punctuation removal, tokenization).
   * Convert text to numeric features with `CountVectorizer` and TF‑IDF.
   * Train three models (Naive Bayes, Linear SVM, Random Forest).
   * Evaluate using accuracy, precision, recall, and F1‑score.
   * Visualise results (accuracy bar chart, confusion‑matrix heatmaps).
   * Include a TextBlob baseline for quick sentiment estimation.

Both modules are production‑ready, well‑commented, and use only the dependencies listed in `requirements.txt`.

## Setup Instructions
1. **Clone the repository** (or copy the folder to your machine).
2. **Create a virtual environment** (recommended):
   ```bash
   python -m venv venv
   venv\Scripts\activate   # Windows
   # source venv/bin/activate   # macOS/Linux
   ```
3. **Install the required packages**:
   ```bash
   pip install -r requirements.txt
   ```
4. **(Optional) Verify installations**:
   ```bash
   python -c "import nltk, textblob, sklearn, pandas, matplotlib, seaborn"
   ```

## Usage
### 1️⃣ Resume Information Extractor
```bash
# From the project root
python resume_extractor\extractor.py
```
The script reads `sample_resumes.txt`, extracts emails and phone numbers, and writes a nicely formatted JSON array to `resume_extractor\output.json`.  You can replace `sample_resumes.txt` with your own resumes (one per line) and re‑run the script.

### 2️⃣ Sentiment Classification System
```bash
# Launch Jupyter Notebook
jupyter notebook sentiment_classification\sentiment_analysis.ipynb
```
The notebook walks you through each step.  Replace `dataset/sentiment_data.csv` with your own labeled dataset if desired, then run all cells.  Trained model files will be saved under `sentiment_classification/models/` and visualisations under `sentiment_classification/outputs/`.

## Notes & Tips
- The extractor uses a simple regex; for production use you may want a more sophisticated parser.
- The notebook uses default hyper‑parameters. Feel free to experiment with `LinearSVC(kernel='linear')`, `RandomForestClassifier(n_estimators=300)`, etc.
- All plots are saved automatically; you can open them directly from the `outputs/` folder.
- If you add a large dataset, increase the `test_size` or use cross‑validation for more reliable metrics.
